# Тренажёр «Шлюз»: API для системного аналитика

Интерактивный тренажёр по теме API для учеников курса системного анализа. Продолжает кейс тренажёра «Искра»: сеть автосервисов «Искра Онлайн» открывает API партнёрам — таксопарку «Шашка», ЮKassa, 1С и своим внутренним сервисам.

Открыть: https://andreypol1991.github.io/api-trainer/

## Программа

| Модуль | Тренировка | Что внутри |
|---|---|---|
| 1 · Основы API | 1·1 Что такое API и зачем оно нужно | карта интеграций, адрес запроса, контракт; встреча с «Шашкой» (факты в блокнот), первые запросы в живой консоли |
| | 1·2 HTTP изнутри | анатомия сообщения, методы и идемпотентность, коды; консоль с миссиями на 201/409/415/422/405 |
| | 1·3 Виды API и подходы к интеграции | REST, SOAP, gRPC, GraphQL, WebSocket, вебхуки, брокеры, файлы; калькулятор «опрос против вебхука»; карта интеграций |
| 2 · REST | 2·1 REST API | ограничения REST, модель Ричардсона, ресурсы и адреса, дерево ресурсов; проектирование эндпоинтов |

В каждой тренировке — 3 раздела теории и 5–6 практических заданий с проверкой и разбором.

## Как устроено

- Статический сайт без сборки: `index.html` + `js/*.js`. Движок — тот же, что в «Искре» (`core.js`, `ui.js`, `app.js`), набор заготовок заданий — `kit.js`.
- `js/api-data.js` — учебный сервер API «Искры» в памяти браузера: настоящие коды, заголовки, ошибки RFC 9457, токены и права, правила записи, ключ идемпотентности, ETag. Проверки консольных заданий заново прогоняют журнал запросов на чистом сервере, поэтому остаются чистыми функциями от ответа. Там же SHA-256/HMAC для JWT и вебхуков.
- `js/x-system.js` — справочник «API Искры» (кнопка в шапке).
- Прогресс хранится в `localStorage` под ключом `amp-api-shluz-trainer-v1`.

## Разработка

```bash
bash _dev/test.sh              # автотест всех тренировок в headless Chrome
bash _dev/test.sh a2-rest      # одна тренировка
bash _dev/shot.sh a2-rest      # скриншот → _dev/shots/
```
